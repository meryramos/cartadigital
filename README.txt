CÓMO PUBLICAR EN GITHUB:
1. Crea un repositorio público, por ejemplo: mery-ramos.
2. Sube TODO el contenido de esta carpeta a la RAÍZ del repositorio (index.html debe quedar en la raíz).
3. En Settings > Pages > Build and deployment: Deploy from a branch, main y /(root), Save.
4. Cuando Github Pages publique, tendrás un enlace https://USUARIO.github.io/mery-ramos/

CÓMO EDITAR CATÁLOGO:
- Abre datos/productos.js y modifica price, title, subtitle y variants.
- Precio null = precio por confirmar en WhatsApp. No se asignaron precios no facilitados.
- Añade/reemplaza imágenes en img/ y modifica el campo image correspondiente.
- El WhatsApp para pedidos es 51922606915 (en js/app.js e index.html).
- Instagram es @meryramos.23.

IMPORTANTES SOBRE IMÁGENES:
- Los chupetes y waffles se recortaron de los menús facilitados, con fondo blanco uniforme.
- En frappés y milkshakes se crearon VISTAS ILUSTRATIVAS de los sabores a partir de las imágenes de referencia (variación de tonos). No son fotos reales de cada preparación. Reemplazar por fotos definitivas si se quiere exactitud del producto.

- El catálogo puede editarse sin conocimientos de servidor; solo GitHub Pages.
